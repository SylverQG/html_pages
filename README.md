# 📂 HTML 实验室

一个用 AI 生成的单文件 HTML 作品集，由 GitHub Actions 自动扫描仓库并生成导航首页。

👉 **[在线预览](https://你的用户名.github.io/你的仓库名/)**

---

## ✨ 特性

- 🔍 **实时搜索** — 首页内置搜索框，输入即过滤
- 📁 **按目录分组** — `games/`、`demos/`、`ui/` 等自动分 section
- 🏷 **智能命名** — 优先读取 HTML 的 `<title>` 标签作为展示名
- 🌗 **明暗主题** — 右上角一键切换，记忆你的偏好
- 📱 **移动端适配** — 卡片布局自动响应屏幕尺寸
- ⚡ **零维护** — push 新 HTML 文件即自动更新首页，无需手动编辑
